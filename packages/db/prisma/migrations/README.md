# Migrations

This folder is normally auto-populated by `prisma migrate dev`.

## Order of migrations for v0.1

1. `init` - generated by `prisma migrate dev --name init` (the Prisma schema).
2. `enable_rls` - hand-written SQL migration enabling Row-Level Security and
   defining policies for every tenant-owned table. This will be created in
   a later step of the setup process.
3. `extra_indexes` - additional performance indexes that aren't expressible
   via Prisma schema.

## Never edit a migration after it's merged

If you need to fix or extend something, create a new migration. Editing
a merged migration will diverge developer DBs from production.
